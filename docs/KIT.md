# CashPilot kit

Drop this folder's content at the root of your project repo (it already has the right layout), then open OpenCode there.

```
docs/
  PROJECT.md          functional spec (converted from the course brief)
  ARCHITECTURE.md     course architecture (Next.js + Clean Architecture + monorepo)
  DESIGN.md           design system for Stitch and the UI
  reference/cpj-reference.png   style/structure reference
.opencode/skills/clean-nextjs-monorepo/SKILL.md   rules OpenCode must follow
prompts/
  01-understand-project.md      paste into OpenCode first
  02-design-with-stitch.md      paste into OpenCode after phase 1
  03-stitch-screen-prompts.md   copy-paste prompts for Google Stitch
```

Order: Prompt 1 → answer questions → Prompt 2 (or use the Stitch prompts directly) → approve designs → implementation.
